# Challenges at Work: content and sources

The 60 devotionals, reflection questions, practices, and prayers in `src/workplaceContent.js` are original writing for this app. They address workplace situations through the selected biblical passages; they are not copied from a published devotional plan.

Scripture quotations are the unmodified **World English Bible, Protestant Edition (WEB)**, downloaded from the publisher’s [offline HTML archive](https://ebible.org/engwebp/engwebp_html.zip) on October 24, 2026. Verse text is bundled locally in `src/workplaceScriptures.json` so it works offline. Layout whitespace and HTML annotations are removed. See the publisher’s [public-domain declaration](https://ebible.org/engwebp/copyright.htm). The app labels WEB text explicitly when the preferred translation is unavailable locally and links to the selected version through the existing Bible providers.

The existing Job Seeking content and translation entries are preserved. Theme selection is stored on this device. Completion records for both themes use the existing local/cloud progress object, with numeric keys retained for Job Seeking and `challenges-at-work:N` keys for the new theme. Resetting progress affects only the active theme. No database migration is needed.
